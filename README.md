# WeatherPressureBot
WeatherPressureBot — это специализированный Telegram-бот, предназначенный для оперативного сбора и визуализации метеорологических данных. Бот автоматизирует процесс получения актуальных показателей атмосферного давления с сети метеостанций России и формирует наглядные картосхемы.
