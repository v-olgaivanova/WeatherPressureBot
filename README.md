# WeatherPressureBot
WeatherPressureBot — это специализированный Telegram-бот, предназначенный для оперативного сбора и визуализации метеорологических данных. Бот автоматизирует процесс получения актуальных показателей атмосферного давления с сети метеостанций России и формирует наглядные картосхемы. \
✨ Основные возможности 
Сбор данных в реальном времени: Бот выполняет парсинг актуальных архивов метеоданных с портала «Погода и Климат».\
Автоматизированный ГИС-анализ: Интеграция с библиотекой GeoPandas позволяет автоматически сопоставлять данные метеостанций с векторными контурами регионов (из SHP-файлов). \
Dизуализация:Создает тематическую карту выбранного региона. \
Применяет цветовую индикацию: красные точки для областей повышенного давления (выше нормы <b>1013.25<\b> гПа) и синие точки для пониженного давления.Наносит точные числовые значения давления непосредственно на карту рядом с каждой станцией. \
